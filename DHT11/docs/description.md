<h4> Project description <h4>

Objective:

To demonstrate reading temperature and humidity using a DHT11 sensor for environmental monitoring in IoT projects.

---

Components Required:

- DHT11 temperature and humidity sensor
- 10kΩ resistor (pull-up)
- Arduino board
- Breadboard and connecting wires

---

<img src="https://www.electronicshub.org/wp-content/uploads/2015/05/Arduino-DHT11-Circuit-Diagram.jpg" width="400"/>

Working Principle:

The DHT11 sensor measures ambient air temperature and humidity, communicating data via a single digital pin using a proprietary protocol.

---

Circuit Description:

1. Connect the DHT11 data pin to Arduino digital pin 2.
2. Connect a 10kΩ resistor between data pin and VCC.
3. Connect VCC to Arduino 5V.
4. Connect GND to Arduino GND.

---

Applications:

- Weather stations
- HVAC control
- Smart home monitoring
