<h4> Project description <h4>

Objective:

To demonstrate sound generation using a buzzer module for alerts or notifications in IoT projects.

---

Components Required:

- Buzzer module (active or passive)
- Resistor (if needed, e.g., 220Ω for passive buzzer)
- Arduino board
- Breadboard and connecting wires

---

<img src="https://www.electronicshub.org/wp-content/uploads/2015/05/Arduino-Buzzer-Circuit-Diagram.jpg" width="400"/>

Working Principle:

A buzzer converts electrical signals into sound. In this project, the Arduino generates a tone using PWM to make the buzzer beep at 1kHz frequency alternately on and off.

---

Circuit Description:

1. Connect the positive (+) pin of the buzzer to Arduino digital pin 8.
2. Connect the negative (-) pin of the buzzer to GND.
3. If using a passive buzzer, add a resistor in series for protection.

---

Applications:

- Alarm systems
- Notification alerts
- Sound-based feedback in projects
