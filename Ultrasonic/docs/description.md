<h4> Project description <h4>

Objective:

To demonstrate distance measurement using an ultrasonic sensor for obstacle detection or ranging in IoT projects.

---

Components Required:

- Ultrasonic sensor (e.g., HC-SR04)
- Arduino board
- Breadboard and connecting wires

---

<img src="https://www.electronicshub.org/wp-content/uploads/2015/05/Arduino-Ultrasonic-Sensor-Circuit-Diagram.jpg" width="400"/>

Working Principle:

The ultrasonic sensor emits sound waves and measures the time for echo to return, calculating distance based on speed of sound.

---

Circuit Description:

1. Connect Trig pin of sensor to Arduino digital pin 9.
2. Connect Echo pin to Arduino digital pin 10.
3. Connect VCC to Arduino 5V.
4. Connect GND to Arduino GND.

---

Applications:

- Obstacle avoidance in robots
- Parking sensors
- Level measurement
